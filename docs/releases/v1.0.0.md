**Fluxa** es un sistema de turnos y citas open source y autoalojado para cualquier negocio que atiende por orden de llegada. Esta es la primera versión pública.

## Instalar

**Solo quiero usarlo:** descarga `fluxa-1.0.0.zip` (Windows) o `fluxa-1.0.0.tar.gz` (Linux/macOS) en *Assets*, descomprímelo y ejecuta dentro de la carpeta:

```bash
fluxa install      # Windows (PowerShell: .\fluxa install)
./fluxa install    # Linux / macOS
```

El único requisito es Docker. Imagen: `ghcr.io/jmobandod2000/fluxa:1.0.0` (amd64 y arm64).

## Qué incluye

- **Turnos:** kiosco, ticketera térmica 58/80 mm, pantalla de llamado con voz, panel para atender y seguimiento por QR.
- **Citas:** reserva en línea con horario por puesto, agenda del equipo y check-in con prioridad en la fila.
- **Reportes:** tiempos de espera y atención, horas pico, por sección y empleado, con Excel.
- **Para cualquier negocio:** carnicería, barbería, peluquería, autolavado, consultorio, farmacia, banco y más, en español, English y português.

Detalle en el [CHANGELOG](https://github.com/jmobandod2000/fluxa/blob/main/CHANGELOG.md).
